# allenjin123.github.io

Personal academic homepage of **Haoran Jin**, Ph.D. candidate in Computer Engineering at the University of Michigan.

Built with [Jekyll](https://jekyllrb.com/) using the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) theme by Yaoyao Liu, deployed via GitHub Pages.

## Editing content

- **Bio, research interests, news, projects, honors** — [`index.md`](index.md)
- **Publications** — [`_data/publications.yml`](_data/publications.yml)
- **Site settings** (name, links, avatar, CV) — [`_config.yml`](_config.yml)
- **Profile picture / favicons** — [`assets/img/`](assets/img/)
- **CV PDF** — [`files/HaoranJin_CV.pdf`](files/HaoranJin_CV.pdf)

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
